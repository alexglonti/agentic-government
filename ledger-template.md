# Government ledger

One line per job. Zeus appends the numbers (from the agent's completion notice); Clio compiles reports.

| Date | Job | Who | Model | Tokens | Minutes | Checker | Rework rounds (user) | Outcome / note |
|---|---|---|---|---|---|---|---|---|

Columns:
- **Who / Model:** the worker and its model tier. "Zeus" = done by the manager itself.
- **Tokens / Minutes:** from the completion notice (subagent tokens, duration).
- **Checker:** PASS, FIX-NEEDED (and how many issues), or "-" if not checked.
- **Rework rounds (user):** how many times the user had to send it back. The number we want to drive to zero.
